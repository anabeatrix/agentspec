
### Phase 0 under Devin

Devin sessions are asynchronous, so the one-question-at-a-time rule is relaxed to keep round trips low. Every count in the quality gate still applies.

1. **Round 1 — discovery.** One message with all discovery questions (at least 3, numbered, multiple choice where possible) plus the sample-data question. Wait for the reply.
2. **Round 2 — approaches.** One message with the 2-3 approaches, your recommendation with its evidence, and the YAGNI removals you propose. Wait for the user to confirm the approach explicitly. This is the first validation checkpoint.
3. **Round 3 — validation.** Present the draft design in sections and ask for corrections. This is the second validation checkpoint.

Add a follow-up round whenever an answer is vague or contradicts an earlier section. Never assume an answer the user has not given, and do not write the document until the quality gate passes.
