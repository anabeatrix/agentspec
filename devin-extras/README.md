# AgentSpec for Devin

Generated by `build-devin.sh` from `.claude/` and `devin-extras/`. Do not edit files here; edit the sources and rebuild.

This bundle carries the SDD workflow (Brainstorm, Define, Design, Build, Ship, Iterate) as Devin skills, plus the specialist roles, the knowledge base, the templates, and the contract linter they rely on.

## Install into a repository

From the root of the repository Devin works on:

```bash
cp -r /path/to/agentspec/devin/.agents .
cp -r /path/to/agentspec/devin/.agentspec .
cp /path/to/agentspec/devin/AGENTS.md .   # if AGENTS.md already exists, append the content instead
git add .agents .agentspec AGENTS.md
git commit -m "chore: add AgentSpec SDD workflow for Devin"
```

Devin reads `AGENTS.md` and discovers the skills under `.agents/skills/` on its own.

## Machine setup

The DEFINE and DESIGN phases run a contract check that needs Python with two packages. Add this to the repository's Devin machine setup:

```bash
pip install pydantic pyyaml
```

Without them the check reports that it did not run; the phases still complete.

## Use

Start a Devin session on the repository and invoke a phase:

```text
@skills:sdd-brainstorm "Daily orders pipeline from Postgres to Snowflake"
@skills:sdd-define .agentspec/sdd/features/BRAINSTORM_ORDERS_PIPELINE.md
@skills:sdd-design .agentspec/sdd/features/DEFINE_ORDERS_PIPELINE.md
@skills:sdd-build .agentspec/sdd/features/DESIGN_ORDERS_PIPELINE.md
@skills:sdd-ship .agentspec/sdd/features/DEFINE_ORDERS_PIPELINE.md
```

Each phase commits its document and stops for review. Phase documents live in `.agentspec/sdd/` and travel with the branch.

## Differences from the Claude Code plugin

| Claude Code | Devin |
|---|---|
| Slash commands (`/define`) | Skills (`@skills:sdd-define`) |
| Specialist subagents | Role files under `.agentspec/agents/` that Devin reads and applies itself |
| One question at a time in Brainstorm | Questions batched per round |
| `--judge` cross-model review | Not included |
| Data engineering, review, and visual commands | Not included yet |
